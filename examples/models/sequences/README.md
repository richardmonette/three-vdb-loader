# Demo sequences

These frames are loaded by the three.js example `webgpu_loader_vdb` from this repository's
GitHub Pages site, so their paths and contents are part of a published page. Do not rename,
move or regenerate them. `sequences.lock` records every file's size and SHA-256, and
`node tools/lock.mjs` (run by CI) fails when a locked file changes or disappears.

To publish a different sequence, add it under a new directory and lock it with
`node tools/lock.mjs --write`. The old one stays.
